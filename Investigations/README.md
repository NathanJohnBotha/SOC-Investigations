# SOC Security Investigations

This directory contains hands-on security investigations
conducted as part of my SOC Analyst portfolio.

## Investigation Methodology

Each investigation follows six key questions:

1. What fired and why?
2. What do the logs show?
3. Who and what is affected?
4. Is it a true positive or false positive?
5. What is the impact?
6. What is the next action?

## Documentation

Each investigation includes:

- Alert summary
- Log analysis and supporting evidence
- Affected users and systems
- Alert classification
- Impact assessment
- Response actions and recommendations
- Investigation timestamps in UTC

All investigations follow a standardized SOC investigation
template to ensure consistent documentation.
